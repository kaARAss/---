Пошаговая инструкция: Подключение GitHub и Yandex Cloud

Пройдите эти простые шаги, чтобы сайт обновлялся мгновенно при каждом нажатии "Опубликовать"

1 Создание токена на GitHub (2 минуты)

Токен позволяет админ-панели безопасно сохранять файлы в ваш репозиторий без ввода логина и пароля:

  1. Войдите в свой аккаунт на github.com/settings/tokens.
  2. Нажмите Generate new token (classic).
  3. В поле Note напишите: Tais-Show Admin Panel.
  4. В блоке Select scopes поставьте галочку напротив repo (Full control of private repositories).
  5. Нажмите зелёную кнопку Generate token внизу страницы.
  6. Скопируйте полученный ключ (начинается с ghp_...) и вставьте его во вкладку "GitHub и Публикация" в этой админ-панели!
2 Подключение Yandex Cloud (Вариант на выбор)

Ваш сайт на домене таисшоу.рф может работать в Yandex Cloud двумя удобными способами:

Способ А: Виртуальная машина Yandex Compute Cloud (Node.js + Nginx)

Сервер Express работает прямо на виртуальной машине. Когда вы нажимаете кнопку «Сохранить», файлы обновляются моментально на сервере, а кнопка «Опубликовать» делает коммит в GitHub.

Способ Б: Yandex Serverless Containers / Object Storage

При каждом коммите в GitHub срабатывает GitHub Action, который за 30 секунд автоматически выгружает свежую версию сайта в Yandex Cloud.

  • Токен GitHub (PAT), созданный по шагу 1 (или введите его сами во вкладке "GitHub и Публикация").
  • IP-адрес или доступ к виртуальной машине Yandex Cloud (если сайт размещен на ВМ).
